# Counter / Voting Contract

Combines a simple counter with one-wallet-one-vote logic.

## Requirements
- Node.js 18+
- npm

## Install
```bash
npm install
```

## Run tests
```bash
npm test
```

## Local deployment
Terminal 1:
```bash
npm run node
```
Terminal 2:
```bash
npm run deploy:local
```

## Compile
```bash
npm run compile
```

This project is intentionally self-contained and uses Hardhat's local Ethereum network.
