# Simple Wallet

Beginner wallet with per-user deposits and withdrawals using checks-effects-interactions ordering.

## Requirements
- Node.js 18+
- npm

## Install
```bash
npm install
```

## Run tests
```bash
npm test
```

## Local deployment
Terminal 1:
```bash
npm run node
```
Terminal 2:
```bash
npm run deploy:local
```

## Compile
```bash
npm run compile
```

This project is intentionally self-contained and uses Hardhat's local Ethereum network.
